# MSS AP Patcher
### Requirements
- Python 3
### Installation Instructions
- Download and extract the latest release from the releases page.
- Place (a copy of) your unmodified Mario Super Sluggers game file in the /vanilla directory. ISO, CISO, and WBFS are supported file formats.
### Usage Instructions
- Obtain the patch file (.apmss) from the host.
- Windows: Drag the patch file onto patcher.bat.
- Linux: Run `patcher.sh /path/to/patch.apmss` in the terminal.
- If successful, a WBFS file with the same name as the patch should have been created. Use this when connecting to Archipelago.
